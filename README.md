Entry for the [make.fun bounty "The Funniest Toaster Error Message"](https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd).

The program writes one line — the error message a kitchen toaster shows
its owner — to `/output/entry.txt`:

> ERROR: Insufficient funds. Your bread has been declined. Please insert a richer loaf.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The entry is 85 characters, one line, no trailing newline. The file is
written directly and given mode 0644.
